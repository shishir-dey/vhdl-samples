Sequential Logic

Documentation for sequential logic circuits.

Note

This section is under development. More comprehensive documentation will be added soon.

Overview

Sequential circuits covered in this project:

  • Flip-Flops: D-type, T-type memory elements

  • Latches: Level-sensitive storage elements

  • Registers: Multi-bit storage units

  • Counters: Up/down counting circuits

  • State Machines: Finite state automata

These circuits form the foundation of digital memory and control systems.
