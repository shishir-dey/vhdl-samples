Combinational Logic
===================

Documentation for combinational logic circuits.

.. note::

   This section is under development. More comprehensive documentation will be added soon.

Overview
--------

Combinational circuits covered in this project:

- **Adders**: Half adders, full adders, multi-bit adders
- **Decoders**: Binary to one-hot decoders  
- **Multiplexers**: Data selectors and routers
- **Comparators**: Magnitude comparison circuits
- **Shifters**: Bit manipulation circuits

See :doc:`gates` for basic building blocks used in these circuits.
